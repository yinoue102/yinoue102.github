# ステージ方針

## 手動版の位置づけ

手動版は，CPU内部の動きを体験するチュートリアル編である．
配置変更はまだ行わず，あらかじめ決められた配置のステージを複数用意する．
プレイヤーは小人を手動で動かし，命令列を順番に実行する．

## ステージ構成案

### ステージ1：材料置き場を使おう

ねらい：

- 命令列を順番に実行する
- 倉庫から材料を取る
- 材料置き場に材料を一時保存する
- 組立台で材料を処理する
- 完成箱に結果を保存する

CPU対応：

- メモリ
- レジスタ
- ALU
- プログラム
- クロック

### ステージ2：3つの材料をそろえよう

実装済み．

ねらい：

- 複数の材料置き場を使う
- レジスタが複数あることを理解する

内容：

- 材料置き場A，B，Cを使う
- 注文はロボット1体
- 必要材料は「頭」「体」「足」
- 3つの材料は，A/B/Cのどこに置いてもよい

### ステージ3：同じ処理をくり返そう

実装済み．

ねらい：

- 同じ命令の並びを繰り返すことに慣れる
- 繰り返し処理の導入にする

内容：

- くるまを2台作る
- ステージ1の命令列を2回繰り返す
- 1台目を完成箱に入れたあと，ステージクリアせず2台目の命令へ進む

### ステージ4：遠いと時間がかかる

ねらい：

- 移動にもターンがかかることを理解する
- データ移動コストを体験する

案：

- ステージ1と同じ注文
- ただし設備配置を遠くする
- 同じ命令でもターン数が増えることを見せる

### ステージ5：材料置き場が足りない

ねらい：

- レジスタ数の不足を体験する

案：

- 必要材料が3つ
- 材料置き場が2つしかない
- 一時的に保存できる数に制約があることを体験させる
