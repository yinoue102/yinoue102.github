# こびとCPU工房 ゲーム仕様

## 目的

中学生向けに，CPU内部の基本動作を体験的に理解するためのHTML試作ゲームである．
プレイヤーは小人を手動で動かし，固定された命令列に従っておもちゃを完成させる．

## 世界観

プレイヤーは，小人が働くおもちゃ工房を操作する．
工房の要素はCPUの要素に対応する．

| 工房 | CPU |
|---|---|
| 倉庫 | メモリ |
| 材料置き場 | レジスタ |
| 組立台 | ALU |
| 完成箱 | メモリへの保存 |
| 命令列 | プログラム |
| ターン | クロック |

## 基本ルール

- 小人は1ターンに1アクションだけ実行できる．
- 移動も1アクションである．
- 小人は上下左右に1マス移動できる．
- 小人が持てる材料は1個までである．
- 材料置き場1つにつき，材料は1個だけ置ける．
- アクションは，対象設備と同じマスに小人がいるときだけ実行できる．
- 画面上のアクションボタンは1つだけで，現在の命令に応じて「材料を取る」「材料置き場に置く」「組み立てる」「完成箱に入れる」を実行する．
- 命令列は上から順番に実行する．
- 命令を飛ばしたり，順番を入れ替えたりしない．
- ステージごとに納期ターンと星評価を設定する．

## ステージ1の仕様

盤面は3×3．

配置：

- 倉庫：左上
- 材料置き場A：上中央
- 組立台：右上
- 材料置き場B：右中央
- 完成箱：右下
- 小人初期位置：中央

注文：

- くるま ×1

命令列：

1. 倉庫で「タイヤ」を取る
2. どちらかの材料置き場に「タイヤ」を置く
3. 倉庫で「ボディ」を取る
4. 空いている材料置き場に「ボディ」を置く
5. 組立台で「くるま」を作る
6. 完成箱に「くるま」を入れる

材料置き場の扱い：

- タイヤとボディは，材料置き場A/Bのどちらに置いてもよい．
- ただし，1つの材料置き場に置ける材料は1個までである．
- 2つ目の材料は，空いている材料置き場に置く必要がある．

組み立て条件：

- 2つの材料置き場に「タイヤ」と「ボディ」が1つずつある
- 小人が組立台にいる
- 小人が何も持っていない

星評価：

- ★★★：16ターン以内
- ★★：20ターン以内
- ★：24ターン以内

## ステージ2の仕様

盤面は3×3．

配置：

- 倉庫：左上
- 材料置き場A：上中央
- 組立台：右上
- 材料置き場B：右中央
- 材料置き場C：左下
- 完成箱：右下
- 小人初期位置：中央

注文：

- ロボット ×1

命令列：

1. 倉庫で「頭」を取る
2. 空いている材料置き場に「頭」を置く
3. 倉庫で「体」を取る
4. 空いている材料置き場に「体」を置く
5. 倉庫で「足」を取る
6. 空いている材料置き場に「足」を置く
7. 組立台で「ロボット」を作る
8. 完成箱に「ロボット」を入れる

材料置き場の扱い：

- 頭，体，足は，材料置き場A/B/Cのどこに置いてもよい．
- ただし，1つの材料置き場に置ける材料は1個までである．
- 3つの材料をすべて別々の材料置き場に置く必要がある．

組み立て条件：

- 3つの材料置き場に「頭」「体」「足」が1つずつある
- 小人が組立台にいる
- 小人が何も持っていない

星評価：

- ★★★：24ターン以内
- ★★：30ターン以内
- ★：36ターン以内

## ステージ3の仕様

盤面は3×3．配置はステージ1と同じである．

配置：

- 倉庫：左上
- 材料置き場A：上中央
- 組立台：右上
- 材料置き場B：右中央
- 完成箱：右下
- 小人初期位置：中央

注文：

- くるま ×2

命令列：

1. 1台目：倉庫で「タイヤ」を取る
2. 1台目：どちらかの材料置き場に「タイヤ」を置く
3. 1台目：倉庫で「ボディ」を取る
4. 1台目：空いている材料置き場に「ボディ」を置く
5. 1台目：組立台で「くるま」を作る
6. 1台目：完成箱に「くるま」を入れる
7. 2台目：倉庫で「タイヤ」を取る
8. 2台目：どちらかの材料置き場に「タイヤ」を置く
9. 2台目：倉庫で「ボディ」を取る
10. 2台目：空いている材料置き場に「ボディ」を置く
11. 2台目：組立台で「くるま」を作る
12. 2台目：完成箱に「くるま」を入れる

材料置き場の扱い：

- 各くるまを作るたびに，タイヤとボディを材料置き場A/Bへ一時保存する．
- タイヤとボディは，材料置き場A/Bのどちらに置いてもよい．
- 1台目を組み立てると材料置き場は空になり，2台目で再利用できる．

クリア条件：

- 2台目の「くるま」を完成箱に入れる．
- 1台目を完成箱に入れただけではステージクリアにならず，次の命令へ進む．

星評価：

- ★★★：34ターン以内
- ★★：42ターン以内
- ★：50ターン以内
